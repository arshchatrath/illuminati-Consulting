# Illuminati Consulting: landing page rebrand

A landing page for [illuminaticonsulting.ai](https://www.illuminaticonsulting.ai/), built on their live site's stack: **Next.js (App Router) + Tailwind CSS v4**. The page is pre-rendered to static HTML, so it reads fine with JavaScript off; the scroll story switches on in the browser.

**Concept: "The Strategy Room."** A consultant's desk at night under one gold lamp. As you scroll, the scene's frame grows, then compresses to the right, and the camera moves through four chapters that follow the brand line *Insights → Fit → Action → Value*:

| # | Chapter | What happens in the scene |
|---|---|---|
| 1 | Insights: "Every problem, illuminated." | Gold strings connect the 8 business-problem notes on the board to a "best-fit AI solution" card |
| 2 | Fit: "The best-fit answer, not the flashiest." | Gold solution pieces snap into the problem puzzle pieces on the desk |
| 3 | Action: "Built with your team. Run in production." | Agent nodes light up on the laptop |
| 4 | Value: "Measured where it matters." | The city outside lights up, next to the real results (+4%, +3%, 40%, 20%) |

The design is inspired by [illoca.unseen.co](https://illoca.unseen.co/). The scene is 2.5D: four SVG depth layers (sky, wall, desk, foreground) moved by a virtual camera, with parallax.

```
app/page.jsx               page markup and copy
app/layout.jsx             fonts (self-hosted via next/font), meta tags
app/globals.css            design tokens (colour, fluid type, spacing, motion) + all styles
app/opengraph-image.jsx    social share card, generated at build time
lib/scene.js               draws the Strategy Room SVG layers (rendered on the server)
lib/story.js               scroll timeline: frame shape, camera, chapters, section interactions
components/PageEffects.jsx starts lib/story.js in the browser and cleans it up
public/img/                logo and leadership photos (from the current site)
docs/current-site/         verbatim content inventory and screenshots of the current site
```

**Run locally:** `npm install`, then `npm run dev` and open http://localhost:3000. For a production check: `npm run build && npm start`.

**Tuning the story:** the timeline is `KEYS` in `lib/story.js`. Each key has a scroll position `t` (0–1), a frame shape (`hero`, `full` or `split`) and a camera `[x, y, zoom]` in scene coordinates (1600×1000). Chapter text timing is set in `CHAPTERS`.
